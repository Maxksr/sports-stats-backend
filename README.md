# Sports Statistics Backend

A Spring Boot backend application for managing sports teams, players, matches, statistics, and leaderboards.  
The project focuses on backend development, REST API design, authentication, and database management.

## Features

- User registration and authentication
- JWT-based authentication and authorization
- Secure API endpoints using Spring Security
- Team management
- Player management
- Match management
- Player statistics tracking
- Leaderboard system
- CRUD operations for application entities
- Pagination implemented for player data retrieval
- Global exception handling
- Layered architecture 

## Technologies

### Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA / Hibernat

### Database
- H2 Database (development/testing)
- JPA/Hibernate ORM
- Relational database concepts
